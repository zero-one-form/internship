# YOU, THY ARIA — ゲームデザイン文書（GDD）

最終更新: 2026-10-20 ／ 対象ビルド: `claude/game-development-completion-kfwlre`

## 1. 一行で
剣と術、ふたつの魂を切り替えて戦う、スマホ片手で遊べる斜め見下ろしのアクションRPG。全50層の「深淵」を潜り、主題歌「YOU, THY ARIA」の物語にたどり着く。

## 2. デザインの柱（Pillars）
すべての仕様判断はこの3本に照らして決める。どれにも効かない機能は作らない。

| 柱 | 意味 | 具体例 |
|---|---|---|
| **ふたつの魂** | 剣（近接・硬い）と術（遠距離・範囲）を切り替えるのが最も強い遊び方 | 変身は1秒・無料、スキルの待ち時間は型ごとに独立、装備も剣と杖を両方持つ |
| **手のひらの爽快感** | 片手・短時間で「気持ちいい」が必ず起きる | ヒットストップ、画面揺れ、コンボ、自動ターゲット、自動回復薬 |
| **一層ずつ深く** | 毎回少し違う潜行と、少しずつ強くなる実感 | 地形9種×地層10種、目標5種、呪い、祝福、位階Ⅰ〜Ⅹ |

## 3. ループ
- **コア（30秒）**: 群れを見つける → 剣/術を切り替えて倒す → 経験値・ゴールド・装備
- **階（3〜5分）**: 階の目標（殲滅・賞金首・宝探し・耐久・封印石）→ 門 → 次の階。5層ごとにボスと祝福
- **セッション（15〜30分）**: キャンプで準備（装備・強化・依頼・アリアの演奏）→ 深淵へ → 帰還
- **メタ（日・週）**: 歌の加護（1日1回）、共闘ボス（1日3回）、週間ランキング、位階、ペット

## 4. 主要システムの現仕様（数値は src を正とする）

### 4.1 成長
- 必要経験値 `22·L^1.6+8`（b_core `expNeed`）
- 敵経験値 `基礎·(1+0.45(lvl−1))·(1+lvl/150)`（後半の伸びに合わせて補正、2026-10 変更）
- Lvアップごとに能力値3・スキル2。おまかせ配分あり

### 4.2 戦闘
- 攻撃間隔: 素早さで線形に短縮し、下限（剣0.32秒/術0.42秒）以降は逓減しながら伸び続ける（最終下限は各0.55倍）
- 軽減: 上限75%。胴防具は `3+27(1−e^(−il/60))` で飽和（序盤は従来並み、後半は頭打ち）
- 回復薬: 最大HPの40%、再使用1.5秒、所持上限30個

### 4.3 ボス
- 予告つき大技（叩きつけ・突進・地割れ）は1撃で最大HPの38%まで、弾は14%まで（h_dungeon `BOSS_HIT_CAP`）
- 狙い: 「避ければ勝てる」。一撃で倒れる理不尽をなくし、回復薬連打ではなく回避を報酬にする

### 4.4 装備
- 装備Lv上限400（位階でも装備が伸びる）。割合系の追加効果（攻撃%・会心・速さ・軽減など）は il99 で頭打ちにして、上限値に張り付くのを防ぐ
- il100以上は名前に「真・／極・／神・」が付く

### 4.5 ミニゲーム「アリアの演奏」
- キャンプの「♪演奏」から。2レーン（左＝剣・右＝術）、主題歌の拍データ161拍から譜面を生成
- 難易度: ふつう81／むずかしい161／達人221ノーツ。判定 ±50/100/150ms
- ランクB以上で1日1回: ゴールド＋「歌の加護」（次の潜行の最初に祝福を1つ選べる）
- 柱との対応: 剣/術の左右レーン（ふたつの魂）、短時間（64秒）で爽快感、報酬は潜行につながる

## 5. 最初の5分（FTUE）
1. オープニング（主題歌）→ 説明画面は5項目のみ（移動・攻撃・切り替え・回復薬・焚き火）。残りは「もっと詳しく」に格納
2. キャンプのミーナ「！」→ 最初の依頼（ゴブリン5体）
3. 週替わりの呪いは B6F から（B1〜B5 は基本を覚える区間）
